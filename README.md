# Linux Commands Reference

A practical Linux commands reference created as part of my continuous learning journey in Linux, Networking, DevOps and Cloud Computing.

## Topics Covered

- File and Directory Management
- User and Group Management
- File Permissions
- Process Management
- Networking Commands
- Disk and Storage Management
- Service and Log Management
- Bash Scripting
- System Administration

## Purpose

This workbook serves as a quick reference for commonly used Linux commands, their purposes and practical examples.

It is intended for beginners, aspiring Linux administrators, Network Engineers, DevOps Engineers and Cloud Engineers.
